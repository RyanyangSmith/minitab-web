# 产品需求文档（PRD）— MiniTab Web V2

## 1. 产品概述

MiniTab Web 是一款运行在浏览器中的统计分析与数据可视化工具，面向需要做质量分析、实验数据处理和统计检验的工程师、研究人员与质量管理人员。V2 以 V1 为基线，重点修复统计正确性、表格交互和工程质量问题。

## 2. 目标用户

- 质量工程师：过程能力分析、缺陷 Pareto 分析。
- 研发/实验人员：正态性检验、线性回归。
- 数据分析初学者：散点图、箱线图等可视化探索。

## 3. 产品目标

- 提供 6 种常用分析：过程能力分析、正态检验、线性回归、散点图、箱线图、帕累托图。
- 类 Excel 的编辑体验，支持非连续复制、粘贴扩表、撤销/重做。
- 1000 行 x 50 列以内流畅编辑，首屏 gzip 明显低于 100 KB。
- 全中文界面，数据本地持久化，通过 Netlify 一键部署。

## 4. 功能需求

### 4.1 界面布局

- 顶部 Ribbon：每个分析功能一个按钮，点击后创建结果并自动运行。
- 左侧边栏：树形管理工作表和对应分析结果，支持重命名、删除。
- 右侧工作区：显示电子表格或分析结果，多结果以标签页切换。

### 4.2 分析功能

| 功能 | 输入 | 输出 |
| --- | --- | --- |
| 过程能力分析 | 数据列 + LSL/USL/目标 | 直方图、Pp/Ppk/Cp/Cpk、PPM 表 |
| 正态检验 | 数据列 | AD/SW/KS(Lilliefors) 统计量与 P 值 |
| 线性回归 | X 列、Y 列 | 方程、R/R2、系数表、ANOVA、残差图 |
| 散点图 | X 列、Y 列、可选分组列 | 分组散点图 |
| 箱线图 | 一列或多列 | 并列箱线图与描述统计表 |
| 帕累托图 | 缺陷列 + 可选频数列 | 降序柱状图 + 累积百分比折线 |

### 4.3 电子表格

- 首两行为表头：C1/C2... 列标题和可编辑子标题。
- 支持鼠标拖拽、Ctrl 多选、Shift 扩展、整列选择。
- Ctrl+C 复制选中区域为 TSV，非连续选区按块输出并以空行分隔。
- Ctrl+V 粘贴，目标区域不足时自动扩表，粘贴后焦点移动到数据末尾。
- Ctrl+Z / Ctrl+Y 撤销与重做。
- 行列同时虚拟化，固定表头与行号。

### 4.4 数据持久化

- 工作表、分析结果、打开标签通过 Zustand persist 保存到浏览器本地。
- 存储带版本号，未来结构变更通过 migrate 升级。

## 5. 非功能需求

- 首屏 gzip 体积目标低于 100 KB；分析组件与 ECharts 按需加载。
- 1000 行 x 50 列表格滚动流畅，DOM 中仅保留可视窗口。
- 统计结果与 SciPy/R 参考值对齐，KS 使用 Lilliefors 校正。
- 构建、单测、E2E、类型检查均纳入 CI 质量门禁。

## 6. 验收标准

- 统计测试全绿且锚点与参考值一致。
- 点击 Ribbon 即创建并自动运行分析。
- 删除工作表后结果、标签页和活动标签无残留。
- 1000x50 表格滚动流畅且仅渲染可视行。
- 无乱码，Netlify 可一键部署。
