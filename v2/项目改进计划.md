# MiniTab 项目改进计划

## 1. 现状基线

V1 可构建，但所有 JS 打成单包约 1.26 MB。V2 已启用 TypeScript 检查，Vitest 共 21 项，18 项通过、3 项失败，均为 Shapiro-Wilk 返回 NaN。

## 2. P0：统计正确性与核心功能

1. 修复 V2 Shapiro-Wilk 移植错误。`poly()` 按 1-based 数组取值，但系数数组实际是 0-based，导致 W 统计量变为 NaN。修复后用 R 或 Minitab 参考输出建立回归锚点。
2. 修复单样本统计量。`descriptiveStats([42])` 因除以 `n - 1` 产生 NaN，需对 `n === 1` 单独处理。
3. 统一回归缺失值配对。V1 将两列非空数据压缩后简单截断，空值位置不同时会错位；V2 统一使用按行配对的数据接口。
4. 完善正态性检验边界。V1 的 Shapiro-Wilk 使用 Blom 分位数和近似 p 值，KS 使用 dMax 估计，需对照参考实现确认精度。
5. 修复 Ribbon 创建空结果的问题。点击分析按钮应生成默认配置、打开结果页并自动执行分析，而不是只创建一个空白面板。
6. 拆分正态检验与过程能力分析。当前“正态检验”面板默认计算 LSL/USL/target 并展示能力分析，与 PRD 功能定义不符。
7. 完善删除工作表的级联清理。删除表时同时清理结果、打开 tab 和 activeTab，避免留下空白页。
8. 修复 V1 列名生成错误。`columnName(0)` 当前返回 CA，应为 C1；V2 已修复，但需补充单测防止回归。

## 3. P1：表格交互与数据体验

9. 统一并修复剪贴板。非连续选区复制不应填充包围盒空格，粘贴需处理空行与焦点丢失问题。
10. 完成表格滚动与虚拟化。V1 表头与表体横向滚动不同步；V2 已修复表头同步，还需补充列虚拟化和固定表头、行号。
11. 增加撤销/重做，覆盖单元格编辑、批量粘贴、删除和扩表操作。
12. 增加数据持久化。工作表、分析结果和配置应支持本地保存，刷新后不丢失。

## 4. P2：工程质量与交付

13. 清理全项目中文乱码。界面、PRD 和技术设计文档中的文本均为编码损坏产物，需恢复为正确中文。
14. 删除 V1 死代码与重复实现，包括未使用的 hooks、组件、剪贴板实现和旧类型声明。
15. 建立质量门禁。CI 执行 `tsc`、ESLint、Vitest 和 Playwright；修复当前 3 个失败测试后再合并。
16. 优化包体积。ECharts 按需引入，分析页面懒加载，生产包显著缩小。
17. 统一部署方案。当前文档、Netlify 配置和 GitHub Pages workflow 不一致，且存在两个重复 workflow；应确定单一部署目标并固定 lockfile。
18. 清理仓库卫生。`_v2_build`、`Users`、`_git_backup` 等目录需移出或纳入版本管理；V2 源码确定正式根目录。

## 5. V2 验收标准

- 全部统计测试通过，并与 R/Minitab 结果一致。
- Ribbon 新建分析后立即可见有效结果。
- 删除工作表不残留结果或空白 tab。
- 1000 行 × 50 列下编辑和滚动无明显卡顿。
- 中文界面无乱码，构建、类型检查、单元测试和 E2E 全部通过。
- 最终可以在netlify轻易部署。

## 7. V2 图表反馈优化（2026-08-02）

- 过程能力分析图标题默认取列子标题或 `C1/C2` 列名（如 `RC 过程能力分析`），新增标题输入框，修改后即时生效并随结果持久化。
- 直方图弃用固定 4 柱的旧逻辑，改为 Freedman-Diaconis/Scott 混合规则并取 1-2-5 进制分箱宽度，默认最少 8 柱，相近数据不再被合并。
- 散点图、线性回归拟合图、残差图启用自适应坐标范围，按数据实际最小/最大值加边距缩放，大数值或小数值数据均能完整展示。
- 新增 `computeHistogramBins`、`computeAxisRange` 纯函数单测，以及标题编辑 E2E；当前 39 项单测、4 项 E2E、typecheck、ESLint、生产构建全部通过。

## 8. V2 交互细节优化（2026-08-02）

- 过程能力分析切换数据列后，未手动修改的规格下限、目标值、规格上限会立即按新列重新计算并填入输入框；手动修改过的值保持不变。
- 图表标题输入框独立成行，规格下限、目标值、规格上限与运行按钮保持在同一直行。
- 直方图柱宽调整为 100%，相邻柱紧密相连，不再出现间隙。
- 箱线图纵坐标按实际数据范围加边距缩放，避免数据被压缩到中部。
- 散点图与线性回归图的 X/Y 轴隐藏端点刻度，并以整数刻度优先展示。
- 过程能力结果新增 CA 值（目标偏移占半公差的比例），兼容旧持久化数据。
- 百万分之不良率表格改为与左右统计表一致的简约横线风格，去除大单元格留白。
- 本轮新增 E2E 覆盖：切换列后默认规格值更新、LSL/USL 同行、CA 值展示；当前 40 项单测、4 项 E2E、typecheck、ESLint、生产构建全部通过。

## 9. V2 分布图细节优化（2026-08-02）

- 直方图分箱增加数据典型步长约束：柱宽不小于数据最小常见间隔，避免小区间下出现大量空柱；默认柱数上限收紧到 30，兼顾稀疏与拥挤。
- 箱线图改用实际数据最小值/最大值作为上下须线端点，图表 max 与下方统计表 max 保持一致，不再因剔除离群点导致两者不一致。
- 本轮验证：42 项单测、4 项 E2E、typecheck、ESLint、生产构建全部通过。
